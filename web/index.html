The sidenote CLI

One file, no install. For Claude Code, Codex, Gemini CLI, Cursor or your own terminal.

# download (Node 20+)
curl -fsSL https://sidenote-sync.netlify.app/sidenote.mjs -o sidenote.mjs
# once, in your own terminal, so the AI never sees the key
node sidenote.mjs key sync-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx
# then
node sidenote.mjs all
node sidenote.mjs append Groceries "- [ ] Lemons"
node sidenote.mjs tick Groceries eggs
